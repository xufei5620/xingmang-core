## scope

本片只处理 NewAPI 页面内 UI 对齐，不新增后端端点、迁移、Action 或凭据写入。

- NewAPI 概览补齐用户总数、今日我方计费、今日上游成本、今日毛利四张核心卡。
- 财务三张金额卡从同一份 `finance/channels/summary` 按 `system_type=newapi` 聚合，覆盖不完整、币种/标度不一致、来源不可用时显式显示“数据不完整/未接入”，不把未知编为 0。
- 请求趋势使用 `newapi.models.usage`，保留 168 小时窗口及来源、新鲜度、水位说明。
- 渠道健康按渠道/上游/分组/成功率/状态展示；缺映射或口径时逐格标记“未接入”。
- NewAPI“支付与财务”保留资金与订单、利润核算两个子页；日期/粒度写入 URL，筛选控件先于短搜索。
- 订单 Connector 尚未接入时保留表头、筛选与诚实空态，不生成样例订单或金额。

## data mapping

| UI | source | honest-state rule |
| --- | --- | --- |
| 概览·用户总数 | `GET /api/v1/metrics`, `newapi.users.total` | 缺失/未初始化显示“— + 未接入” |
| 概览·今日我方计费/上游成本/毛利 | `GET /api/v1/finance/channels/summary`, filter `system_type=newapi` | 逐渠道聚合；覆盖不足保留下界并显示覆盖率/新鲜度 |
| 概览·近 7 日请求量 | `GET /api/v1/metrics`, `newapi.models.usage` | 无可信指标保留布局并标“未接入” |
| 概览·渠道健康 | `GET /api/v1/metrics`, `newapi.channels.status` | 缺上游、分组、成功率口径逐格标明 |
| 资金与订单·区间到账/订阅 | `newapi.recharge.daily` / `newapi.subscription.daily` | 仅日期匹配的单日指标可显示；周/月不冒充合计；部分/未知不显示 0 |
| 资金与订单·订单表 | 未来支付 Connector（M3） | 只读表头、筛选及空态 |
| 利润核算明细 | `finance/channels/summary`, filter `system_type=newapi` | 每个渠道独立展示我方计费、成本、毛利、毛利率，不按上游合并 |
