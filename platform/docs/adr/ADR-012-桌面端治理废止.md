# ADR-012：桌面端治理废止

| 项 | 值 |
|---|---|
| 状态 | 废止 |
| 日期 | 2026-08-26 |
| 来源 | 规格 v2.1 §3 ADR-012（本文件拆分后为唯一权威版本） |

## 背景

早期范围曾包含 Electron 客户端及其发布治理。

## 决策

Electron 客户端及其发布、更新、下载和签名治理全部移出本平台范围。
桌面端仓库继续作为 NewAPI 的 C 端消费者独立存在。

## 理由

桌面端治理与运营控制平面目标无耦合，保留只会扩散范围。

## 边界与后果

平台不承担桌面端任何发布、签名、分发责任。

## 替代方案

保留桌面治理模块：否决。

## 重评条件

无（如未来重新纳入需全新 ADR）。

## 相关契约

无。

## 证据编号

无。
