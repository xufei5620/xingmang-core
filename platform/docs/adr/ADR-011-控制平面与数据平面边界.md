# ADR-011：控制平面与数据平面边界

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-08-26 |
| 来源 | 规格 v2.1 §3 ADR-011（本文件拆分后为唯一权威版本） |

## 背景

控制平台一旦进入用户实时请求路径，其故障将放大为业务故障。

## 决策

控制平台：

1. 不参与用户 API 请求转发；
2. 不影响 NewAPI/Sub2API 正常服务路径；
3. 不成为业务交易强依赖；
4. 不拥有第三方业务数据的最终真相；
5. 不直接写第三方原始业务表；
6. 可以通过只读 API、只读 Projection 和只读副本采集。

## 理由

平台故障不得使用户 API 中转、支付回调或开票用户前端的核心业务停止。

## 边界与后果

见决策条款；违反任意一条即为架构违规。

## 替代方案

平台内联到请求路径：直接否决。
