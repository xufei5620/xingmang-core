# ADR-017：Sub2API 战略去留不阻塞平台建设

| 项 | 值 |
|---|---|
| 状态 | 待决策（不阻塞） |
| 日期 | 2026-08-26 |
| 来源 | 规格 v2.1 §3 ADR-017（本文件拆分后为唯一权威版本） |

## 背景

Sub2API 当前是存量主平台（用户量最大），其长期去留是产品战略问题。

## 决策

Sub2API 必须按主平台优先接入。是否迁移或退役是独立产品战略，不影响平台
先完成监控、告警和 Connector 边界。

## 理由

监控与 Connector 投入在任一战略分支下都不浪费。

## 边界与后果

若在 M1 期间决定退役：

- 缩减长期写能力开发；
- 保留迁移期只读监控；
- 调整影子对账和财务统计范围；
- 另立迁移 ADR。

## 替代方案

等战略定了再接入：因阻塞 M1 否决。

## 重评条件

产品负责人做出 Sub2API 战略决定时（规格 §26 待拍板项 5）。

## 相关契约

`contracts/connectors/`（Sub2API Connector）。
