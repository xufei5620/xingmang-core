## Problem and adaptation

Both helpers previously discarded the full root path before naming short databases. Equal basenames, punctuation/case normalization and invoice non-ASCII fallback could select one test database across different worktrees. Platform DROP SQL therefore also selected the same database.

Both helpers now always append the first 16 hexadecimal SHA-256 characters of the cleaned full root path, retaining the sanitized readable label within PostgreSQL’s 63-byte limit. Invoice uses the absolute path already supplied by worktreeRoot; Bash uses the absolute Git root and lexically cleans path segments, expanding a relative pure-function input against PWD. No dependency or schema changes. The PowerShell wrapper still forwards to the same Bash implementation.

Legacy basename-only databases are not automatically reused, deleted or renamed. Moving a checkout selects a new derived identity; retain the old database until its owner separately reviews cleanup. Explicit invoice non-default DSNs still pass through unchanged and never call ensure. No-Git source-copy behavior is unchanged. Platform naming and comments are the only runtime edits; URL/argument parsing, root lookup and database actions remain unchanged.
