## summary / scope

本片冻结四平面 CPA 边界并提供纯本地审计：

- `ManagementBoundaryV1` 严格 JSON loader：unknown/duplicate/trailing 字段、版本漂移、
  非规范路径、通配/编码/双斜杠/dot/绝对 URL、无限 body/timeout/rate、allow/deny 重叠
  均 fail-closed；canonical route ordering + SHA-256 digest。
- public callback 只允许独立 callback plane 的精确 GET/POST
  `/v0/management/oauth-callback`；inference plane 拒绝整个 management prefix；private
  capability 必须 mTLS + adapter-local key injection；v1 直接拒绝 write/config/auth/API-call/
  plugin/usage/queue/destructive/generic-proxy。
- dependency gates (`Foundation-B`、`R210`、`R214`、`R215`) 与 response projection 敏感
  key deny-list；zero inventory digest 只有显式 `route_inventory_placeholder` 才能加载，
  离线审计永远返回 `partial`。
- `AuditOffline` 只消费调用者提供的结构化、脱敏 evidence projection，输出稳定 code/resource/
  digest/remediation；检查 raw 8317、allow-remote、MANAGEMENT_PASSWORD、IPv4/IPv6、防火墙、
  callback sibling、adapter mTLS/public、redirect、secret exposure、version/route/image drift。
- `cmd/cpa-boundary-audit` 只读 regular local files，拒绝 URL/UNC/NUL/traversal/symlink，
  `--out` 使用 create-only；附模板与 runbook。

## decisions

1. checked-in contract 的 zero route digest 是显式 sample placeholder，不是 target evidence；
   任何真实目标必须替换 exact route inventory digest，否则 report=`partial`/fail-closed。
2. route identity 为 plane + uppercase method + exact unencoded path；callback hostname 与
   inference hostname 必须分开，callback sibling、query、redirect、encoded variant 一律拒绝。
3. private capability 的 destructive/queue/write 或危险能力词即使声明依赖也不在 R213-1
   放行；Foundation-B/R210/R214/R215 仅作为后续片的显式事实门。
4. process/config 原文不进入报告或 evidence digest；仅输出脱敏结构的稳定 SHA-256 与固定资源类。
5. 本片是自拟、待确认的 offline contract，不解锁 R213-2 adapter/lab、R213-3 staging、
   R213-4 production 或任何真实 CPA 管理能力。
