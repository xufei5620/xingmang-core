## Redaction applied

- `email` -> `platformusers.MaskEmail` (the platform's own reviewed masking: local part reduced to 0-2 leading characters, domain kept in full)
- `id` -> one-way per-run pseudonym, `u_` + 16 hex chars of `sha256(salt || "id" || id)` - stable within this run only, not reversible without the salt below, and the salt is not reused across runs
- `username`/`display_name` -> one-way per-run pseudonym, `name_` + 12 hex chars, independent hash domain from `id` (an id and a name with the same raw text never produce the same pseudonym)
- `balance`/`quota` -> every digit zeroed (a bare JSON number's leading digit becomes 1, not 0, only because JSON forbids a leading zero on a multi-digit number - every other digit is 0); sign, decimal point position and whether the upstream sent a JSON string or a bare JSON number are all preserved, so the *shape* evidence Task 4/5 needs survives while the real account balance does not
- `status`, `last_active_at`/`last_login_at`, NewAPI's `DeletedAt` -> passed through unchanged (small known value spaces / soft-delete markers, not PII)
