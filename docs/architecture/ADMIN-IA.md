## 二、横切规则(每一页都适用)

1. **新鲜度铁律(§9.1)**:任何指标必须带来源/observed_at/水位/状态,
   禁止裸数字;未初始化/失败/部分/延迟四态可视且不可互相伪装。
2. **写操作一律走 Action**:页面按钮 = Action 调用;L2+ 在 Foundation-B 前
   由内核拒绝,页面应显示「需审批(Foundation-B)」而不是隐藏。
3. **金额**:整数最小货币单位 + 币种;未知币种 fail closed。
4. **凭据**:任何页面不显示明文;只显示 CredentialRef 与解析审计。
5. **演示数据**:Fake 来源必须有全局不可关闭横幅。
6. **权限**:每页声明所需 scope(路由级 RequireScope);403 提示缺哪个。
