# ADR-007：多前端统一协议，不统一代码；Config Edge 后置

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-08-26 |
| 来源 | 规格 v2.1 §3 ADR-007（本文件拆分后为唯一权威版本） |

## 背景

未来会存在多个自有用户前端；过早建设完整配置中心成本高于收益。

## 决策

多个用户前端可以有独立仓库、独立域名、独立构建和独立发布。统一的是：

- Keycloak 身份；Design Tokens；Frontend SDK；配置协议；发布、预览和回滚模型。

完整 Config Edge、页面配置中心和 Block Runtime 在第二个自有用户前端真实
立项后再建设。当前使用简单配置表。

## 理由

统一协议保证一致性；不统一代码保住各前端独立演进与发布节奏。

## 边界与后果

配置中心未来允许管理：品牌、Logo、主题；导航；公告；FAQ；功能开关；
受控页面区块；草稿、预览、审核、发布和回滚。

禁止下发：

- 任意 JavaScript；
- 未清洗 HTML；
- 生产密钥；
- 服务端业务规则。

## 替代方案

立即建设完整 Config Edge：因无第二前端需求否决。

## 重评条件

第二个自有用户前端真实立项。
