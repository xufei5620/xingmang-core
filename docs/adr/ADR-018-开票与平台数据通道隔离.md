# ADR-018：开票和平台数据通道隔离

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-08-26 |
| 来源 | 规格 v2.1 §3 ADR-018（本文件拆分后为唯一权威版本） |

## 背景

开票系统（Codex 线）已有 Bridge V4 数据通道；平台若复用会形成跨线耦合
与权限混淆。

## 决策

Bridge V4 的角色、函数和 Agent 为开票专属，平台不复用。

平台对 NewAPI/Sub2API 建立独立只读账号，执行四道只读闸：

1. 拒绝可写连接配置；
2. 强制 read-only 事务；
3. 每个新连接复核服务端只读设置和权限；
4. Connector 包内无写路径。

## 理由

通道隔离保证两条线各自可审计、可轮换、可退役。

## 边界与后果

所有凭据通过 CredentialRef 注入，连接配置不直接落库明文。

## 替代方案

复用 Bridge V4：因跨线耦合否决。

## 重评条件

无。
