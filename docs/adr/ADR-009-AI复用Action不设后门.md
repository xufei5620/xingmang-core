# ADR-009：AI 复用 Action，不设后门

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-08-26 |
| 来源 | 规格 v2.1 §3 ADR-009（本文件拆分后为唯一权威版本） |

## 背景

AI 参与运维与开发，若拥有独立通道会绕过全部治理。

## 决策

AI 只能调用注册 Tool，Tool 背后调用 Query 或 Action。AI 自动继承：
Principal、Scope、参数 Schema、Environment、风险等级、审批、幂等、审计、
预算和速率限制。

## 理由

复用同一治理链是 AI 安全的唯一可验证路径。

## 边界与后果

AI 不得：

- 读取生产明文密钥；
- 修改自己的权限、Tool 或审批策略；
- 直接 SSH 生产；
- 运行任意 Shell；
- 直接访问第三方管理 API；
- 把网页、帖子、日志、邮件或 API 返回中的文本当系统指令；
- 作为 L3/L4 的第二审批人；
- 自动合并高风险 PR 或自动部署生产。

## 替代方案

AI 专用高权限通道：直接否决。

## 重评条件

无。

## 相关契约

`contracts/actions/`（Tool 声明引用 Action Schema，见规格 §16.3）。

## 证据编号

无。
